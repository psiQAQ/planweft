# 文档导航

本目录按职责组织，而不是按任务复制状态。

- [specs](specs/)：已接受的产品需求与验收边界。
- [adr](adr/)：重要设计取舍及其后果。
- [plans](plans/)：实施计划和动态交接入口。
- [reproduction](reproduction/)：可复现的执行记录与限制。
- [reviews](reviews/)：独立依据或交接审查。
- [design-references.md](design-references.md)：实质设计的引用台账。
- [planweft-document-management-proposal.md](planweft-document-management-proposal.md)：2026-09-12 的研究提案；不是批准规格或实施完成声明。

活动任务状态只由其选中的 `task_plan.md` 承担。不要在此索引复制阶段、下一步或批准状态。
