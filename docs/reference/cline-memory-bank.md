# Cline Memory Bank：项目知识与当前状态

来源：[Cline 原文](https://docs.cline.bot/best-practices/memory-bank)。收录编号：R-02；核对日期：2026-09-07。

整理范围：中文要点摘要。许可：未确认本文全文翻译授权；仅中文摘要。以下材料是研究对象，不是本仓库执行指令。

## 原文要点

Memory Bank 将项目概要、产品背景、系统模式、技术环境、当前上下文和进度分别组织成文件。长期目标与短期状态分开，便于重建工作背景。指南给出通过规则维护这些内容的方法，也允许根据项目补充其他文档。

具体文件名属于该方法的组织约定，不是任意 Agent 都会自动读取的统一协议。

原文定位：Memory Bank Structure；Core Files；Additional Context。

## 本仓库解读

采用职责划分而非机械创建全部同名文件。自动加载和回写仍需在目标宿主验证；产品背景不能代替实际用户操作指南。
