# Vibe Coding 推荐文档配置：用户提供配文

R-00；来源：用户在“整理 AGENTS 文档资源”会话中提供的中文配文与图片内容，2026-09-07 转入本仓库。原作者和公开文章链接未提供，不编造出处。以下按用户提供内容整理，未获取第三方网页全文。

文章提出把长期有价值的信息从会话搬到文档里，使规划、执行和交接可追溯，按项目需要选择文件：

| 文件 | 原配文用途 |
| --- | --- |
| AGENTS.md | AI 进入项目首先需要知道的信息 |
| DESIGN.md | 整个项目的视觉规则 |
| TODO.md | 当前任务、优先级和开发进度 |
| project-overview.md | 项目整体说明 |
| architecture.md | 架构和数据流 |
| user-guide.md | 面向使用者的功能说明 |
| development.md | 开发方式、命令和回归清单 |
| component-api.md | 组件相关说明 |

核心原则是“每个环节做正确的事”。配文建议至少配置 AGENTS、TODO、user-guide：TODO 在会话重启、丢失或换 Agent 后提供接续点；user-guide 面向不阅读实现代码的人，集中解释如何操作成果；AGENTS/CLAUDE 提供 Agent 的项目入口。无需每个项目都放齐全部文件。
