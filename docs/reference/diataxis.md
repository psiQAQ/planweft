## 原文译文

把这个网站视为手册或工具箱，需要时拿来使用。

理解 Diátaxis 或开始实践，并不需要读完网站全部内容；事实上，我建议你不要这样做。**入门的最好方法是应用它**，无论对象多么小。

先阅读本页获得简要认识。各节链接到更深入的资料；真正动手工作，或反思遇到的文档问题时，再按需阅读。

### 四种文档

Diátaxis 的核心思想是：文档可以辨认出四种基本类型，分别回应四种需要：教程、操作指南、参考资料和解释。它们的目的不同，写法也应不同。

### 教程（Tutorials）

**教程是一堂课**，带领学习者经历一次学习过程。教程总是实践性的：用户在指导者带领下做事。它围绕学习者能够理解的经历设计，指导者对学习者的安全和成功负责。

驾驶课是一个好例子。上课的目的是培养技能和信心，而不是从 A 到 B。软件教程的例子可以是“用 Python 创建一个简单游戏”。

用户通过自己的行动学会东西，而不只是因为有人试图教给他们。

文档的特别困难在于，指导者注定不在现场，无法监控学习者并纠正错误；必须想办法仅通过文字指导实现这种在场作用。

深入阅读：[Tutorials](https://diataxis.fr/tutorials/)、[教程与操作指南的区别](https://diataxis.fr/tutorials-how-to/)。

### 操作指南（How-to guides）

**操作指南处理现实中的目标或问题**，向身处该情境的用户提供实践指导。

它面向已经具备相应能力的用户，预期读者能利用指南完成工作。与教程不同，操作指南关注工作而非学习。

例子包括电影摄影中的“如何保存硝酸纤维素胶片”、软件中的“如何配置帧性能分析”，以及“部署问题排查”。深入阅读：[How-to guides](https://diataxis.fr/how-to-guides/)。

### 参考资料（Reference）

**参考资料包含技术描述，即事实**，为正确做事提供准确、完整、可靠且不夹杂干扰或解释的信息。它属于命题性或理论性知识，而不是行动指南。

像操作指南一样，参考文档服务于正在工作的用户；用户自己需要具备足够能力来正确解读和使用它。

参考资料是中立的，不关心用户正在做什么。一张海图既可以供领航员规划航线，也可以供调查法官使用。

尽可能让参考文档的组织反映所描述事物的结构，就像地图一样。如果某个方法属于某个类，而这个类属于某个模块，文档也应表现出同样关系。深入阅读：[Reference](https://diataxis.fr/reference/)。

### 解释（Explanation）

**解释文档提供上下文和背景**，帮助读者理解并把事物放进更大的图景。它连接不同事物，回答“为什么”。

解释往往需要围绕主题，从不同方向接近它，可以包含观点和立场。

它像参考资料一样属于命题性知识而非行动领域；但其目的与教程一样，是服务学习，而不是完成工作。

教程作者常因急于让学生“知道”更多，而塞入干扰学习、没有帮助的解释。更有效的方式是给最低限度说明，例如“这里用 HTTPS，因为它更安全”，再链接一篇“使用 HTTPS 加密安全通信”的深入文章，留待学习者准备好时阅读。

深入阅读：[Explanation](https://diataxis.fr/explanation/)、[参考与解释的区别](https://diataxis.fr/reference-explanation/)。

### Diátaxis 地图

四种文档及其关系可以用 Diátaxis 地图概括。它不是四种事物的简单清单，而是一种概念组织方式，显示类型之间的联系和区别。大量文档问题的根源，是跨越或模糊了这些边界。

原图关系的中文表达：

| | 学习：获得技能 | 工作：应用技能 |
| --- | --- | --- |
| 行动：用户做什么 | 教程 | 操作指南 |
| 认知：用户知道什么 | 解释 | 参考资料 |

深入阅读：[The map](https://diataxis.fr/map/)。

### Diátaxis 指南针

从地图可见：教程和操作指南关注用户做什么，即行动；参考和解释关注用户知道什么，即认知。另一方面，教程和解释服务于技能获取，也就是学习；操作指南和参考服务于技能应用，也就是工作。

地图不会告诉你该做什么，因为它是参考资料。指导行动需要另一种工具：Diátaxis 指南针。

指南针有两个用途：创建文档时帮助澄清意图，确认你正在做自己以为在做的事情；检查文档时帮助理解其中发生了什么，让问题显现。它没有地图醒目，但在你面对文档难题时能帮助推进。

| 内容用于 | 服务用户的 | 应属于 |
| --- | --- | --- |
| 指导行动 | 技能获取 | 教程 |
| 指导行动 | 技能应用 | 操作指南 |
| 提供认知 | 技能应用 | 参考资料 |
| 提供认知 | 技能获取 | 解释 |

深入阅读：[The compass](https://diataxis.fr/compass/)。

### 开始工作

Diátaxis 的工作流程非常简单：

1. 观察眼前的文档。如果还没开始，眼前也可能什么都没有。
2. 问自己：有没有能改善它的地方？
3. 选一件现在就能做、能够改善文档的事情，无论多小。
4. 完成这件事。

然后重复。就这些。更多操作建议见 [How to use Diátaxis](https://diataxis.fr/how-to-use-diataxis/)。

### 按自己的需要使用

你可以按自己喜欢的方式使用 Diátaxis，不需要信奉它，也没有考试。它完全务实。我认为它是真的，但重要的是它确实帮助人们写出更好的文档。发现其中一个有价值的想法或认识，就拿来使用。

Diátaxis 有详尽的理论，但不需要认同全部理论，甚至不必阅读它们，也不用承诺贯彻到底。

现在只改善一件事，即使此后再也不做，至少也留下了一项改进。实际中每次行动都会提示下一步，只需继续做下去。
