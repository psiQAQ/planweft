# Harness engineering：让仓库知识成为工作依据

## 原文要点

作者描述团队开发内部产品的经验：将 AGENTS.md 缩为入口和导航，把知识、计划和决策放进可版本管理的 docs。冗长入口会挤占上下文、掩盖重点并迅速过期。计划保存进度和决定，检查工具与维护 Agent 帮助发现文档漂移。

这些是特定团队的经验，文章中的规模和效率不能直接作为其他项目的效果保证。

原文定位：We made repository knowledge the system of record；Entropy and garbage collection。
