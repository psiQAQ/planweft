# ADR-0002：通用入口与个人 override 差异稿分离

状态：Accepted；日期：2026-09-07；需求：REQ-08。

## 背景与备选方案

用户希望通用原则对所有使用者生效，个人偏好也提交 Git，但不默认接管其他人的会话。可选：根目录同时存放两份文件；将个人差异放到独立目录；将个人文件完全排除版本管理。

## 决定

采用根 `AGENTS.md` 加 `profiles/personal/AGENTS.override.md`。第三种方案不满足入库要求；第一种会使个人规则在普通检出后默认生效，且 Codex 同目录只读取优先的 override，不原生叠加 base。依据见 [官方指南中文摘要](../reference/codex-agents.md) 的原文定位。

通用原则独立成节；仓库导航限定适用本仓库。个人使用时手工组合通用原则和个人差异为完整 override，不复制仓库导航，也不将使用说明当成偏好。正文仅一行引导，不新增生成器或安装器。

## 后果与确认

个人差异需要随通用原则变化重新审阅，这是选择简单手工组合的成本。静态检查根目录无 override、个人差异入库、使用说明没有声称自动叠加。真实宿主加载实验另列 Not Run，不能用静态文件存在代替模型已遵循。
