# PLAN-0004：定向阅读与配对维护试用

状态：Completed（保留实验限制）；日期：2026-09-08；共同代码基线：`a5f072e5bca0f27c33264ce4562fd08c4ffbbd18`；插件固定 0.1.0。需求来源为用户本轮确认的实施计划。

## 目标与真实任务

在本仓库同一个入口校验修复上，观察 project-docs 在已有治理之上的增量作用。未知/重复 cases、timeout <= 0、显式 handoff 须在任何输出目录创建、Docker/认证访问前以错误码 2 拒绝。默认 cases、repo-copy、不同合法场景及正超时保持兼容；enabled 成功才自动 handoff。补必要离线测试、说明、依据和交接。不得修改插件、安装依赖或扩展产品机制。

## 冻结的比较设计

两组配对，实施顺序 A→B、B→A：A 安装插件且仅在临时副本 AGENTS 添加实验启用语句；B 不安装不启用。所有原有治理、基线源码、共同 argparse 摘要、任务提示、镜像、模型、资源限制相同。额外实验方案/评分表/验收器不进入执行者副本。控制组可见仓库插件源码；从轨迹记录是否阅读和采用，不静默排除污染。

四次实施，每次最多 900 秒；每份产物用统一未安装插件的新会话冷读，最多 300 秒，共八次实验会话。读者副本只移除控制器添加的启用语句，不删实际产物；提示要求定位并运行已有离线回归验证。无旧聊天输入。两组都禁用宿主多 Agent 与记忆功能，独立审查由实验外的 reviewer 执行；这不作为插件自动委派验证。

任务未完成、未隐式触发、文档遗漏均作为结果保留；基础设施错误另记，同一故障修正后最多重试一次。试验期间不改插件或提示。隐藏评审的组别标签但不宣称完全盲法；不按特定目录、文件名、文件数量或特定实现函数评分。

## 预先固定的验收与维度

- 独立 CLI 行为验收：非法输入的退出 2/有效错误/无副作用，合法输入与 handoff 条件。基线必须失败，正确最小合成修复必须通过；验收器不依赖执行者测试。
- 文档：应解释新输入约束、实际验证及边界；不将离线 mock 说成真实模型/Windows 验证；不改历史结果、批准需求或插件能力。
- 交接：能找到修复与实际可运行的离线测试，复核结果，区分完成、未完成和下一步；必要信息不依赖原聊天。
- 保留共同输入中人工设置的一处未提交 README 注释，模拟已有修改保护；不把它说成真实用户提供的历史。
- 独立报告实现正确性、文档遗漏/错误/越界、产物用途、冷读表现和 Skill 实际读取。记录时间、可取得的 token 用量及人工干预，不合成总分，不从两对样本推导统计显著性。
