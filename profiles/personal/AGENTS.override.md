# 个人偏好差异稿

本文件提交到仓库供个人使用，不是独立完整的全局指令，也不在仓库根目录默认生效。

使用时，将根 `AGENTS.md` 的“通用协作原则”部分与下方“个人偏好”手工组合为一份完整 `AGENTS.override.md`，审阅后放入自己的 Codex 用户规则目录（通常为 `~/.codex/`，设置 `CODEX_HOME` 时以该目录为准）。不要带入本仓库导航或此段使用说明，也不要覆盖自己未合并的既有规则。开启新会话后检查指令加载结果。

同目录的 override 优先于 `AGENTS.md`，不会自动叠加，因此不能只复制下方差异并假定通用规则仍会加载。依据见 [Codex AGENTS 指南](../../docs/reference/codex-agents.md)；本仓库未自动安装此配置。

## 个人偏好

- 默认使用中文；代码、API、变量名、命令、错误信息和必要技术术语保留英文。
- 先给结果和必要依据，避免无意义开场、重复总结和机械标签。复杂任务给简短计划，完成时说明验证结果与剩余限制。
- 用户要求完整代码或完整表格时给出完整必要内容；直接修改仓库后，通常报告改动位置和验证结果，不重复粘贴整个文件。
- 解释代码时优先把必要说明写在相关位置的独立注释中；科研分析保留参数、实验条件、单位、公式和不确定性。
- Python 沿用项目指定环境；没有约定时优先已有 `.venv`，需要建立新环境时偏好 `uv`，其次使用已有 conda/virtualenv。系统 Python 仅用于无需额外依赖的简单脚本。
- 安装新包或修改项目依赖前说明内容、原因和影响，并确认已有授权是否覆盖；锁文件与实际环境保持一致，不隐式更换包管理方式。
- 引用既有会话时优先使用直接对话读取能力；信息已能从会话获取时，不转而调试浏览器。
